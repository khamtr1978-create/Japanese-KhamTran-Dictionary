Xuất / sao lưu dữ liệu

Dữ liệu được lưu trong trình duyệt này. Nên xuất file sao lưu định kỳ, và dùng khi chuyển sang máy hoặc trình duyệt khác.

Đồng bộ giữa các máy (qua thư mục Google Drive)

Chọn một file .json nằm trong thư mục Google Drive trên máy. Trang tự ghi từ điển vào file đó sau mỗi thay đổi; máy khác liên kết cùng file sẽ tự gộp từ mới vào. Google Drive lo việc đưa file lên mạng.
Lần đầu trên máy mới: dùng Chọn file đã có… để lấy toàn bộ từ điển từ file đã đồng bộ. Mỗi lần mở lại trình duyệt, Chrome/Edge sẽ hỏi lại quyền ghi file một lần (bấm nút “Cấp quyền đồng bộ” ở góc trên).

Gợi ý nghĩa từ Claude (AI)

Khi tra từ chưa có trong thư viện, Claude sẽ đề xuất Romaji và nghĩa tiếng Việt. Cần khóa API của bạn (lấy tại console.anthropic.com). Khóa chỉ lưu trong trình duyệt này, không nằm trong file HTML; mỗi lượt gợi ý tính phí rất nhỏ theo tài khoản API của bạn.
